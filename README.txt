ANANYA SHARMA — BIOTECHNOLOGY PORTFOLIO

HOW TO RUN
1. Extract this ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Keep the assets folder beside index.html so CSS and JavaScript load correctly.

FILES
- index.html              Main website structure and content
- assets/css/style.css    Layout, colours, typography and responsive styling
- assets/js/script.js     Mobile navigation and expandable career pathway cards

NOTES
- This is a static front-end recreation built with HTML, CSS and vanilla JavaScript.
- It does not include the original Lovable project source, server-side code, database or private assets.
- The hero artwork is recreated with CSS shapes. Google Fonts load from Google Fonts when internet access is available.
- The email, phone and LinkedIn details are reproduced from the public portfolio page. Edit them in index.html if needed.
